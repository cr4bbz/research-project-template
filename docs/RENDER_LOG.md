# Paper-render log

Record every versioned PDF that is shared outside the working team, submitted for review,
or archived. Temporary local renders do not need a row.

| Render file | Paper version | Render date | Source commit / archive ID | Purpose | Notes |
|---|---|---|---|---|---|
| — | — | — | — | Template baseline: no shareable render yet | Replace in a derived project. |

For a public release, the checker requires one row with the exact current render path,
matching version and date, and a non-empty source-commit or archive identifier.
